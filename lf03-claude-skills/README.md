# 3 Claude Skills for YouTube

Three skills I use for the jobs nobody sees when you run a channel alone. Each folder has its own README with install steps and honest limits.

| Skill | What it does | What you need |
|---|---|---|
| [trend-scout](trend-scout/) | Finds videos in your niche that beat their own channel's usual views | Node 18+ and a free YouTube API key (about 5 minutes) |
| [fresh-critic](fresh-critic/) | A brand-new reviewer checks your script, title or description before you post | Nothing extra |
| [daily-digest](daily-digest/) | Reads your X feed in your own Chrome and writes a one-page summary. Read-only | The Claude in Chrome extension, signed in to X yourself |

## Install
1. Copy the skill folder you want into `~/.claude/skills/` (create the folder if it isn't there).
2. Open Claude Code, or the Claude desktop app's Code tab.
3. Ask for the job: "Scout my niche: ...", "Fresh critic this before I post", or "Daily digest".

These are cleaned-up versions of skills I use privately. I ran each public version once on Oct 24, 2026 before sharing it. They don't run on a schedule by themselves.
